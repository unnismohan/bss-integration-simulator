Built for integration teams

Partner behavior, on your terms.

Configure scenarios from sample payloads and tune the response behavior your test needs.

⇄

Sync and async

Return an immediate result or acknowledge first and deliver a callback later, with configurable delay and retries.

JSON and XML / SOAP

Model common partner API formats and map nested fields from request samples into response payloads.

⌘

Dynamic values

Load visibility

A simple workflow

From sample payload to test endpoint.

Define the partner operation

Choose the method, endpoint key, payload formats, and sync or async behavior.

Map request and response fields

Paste representative samples, discover fields, and configure captures and generated values.

Point your BSS at the simulator

Send requests to /sim/<scenario-key> and test against the configured behavior.

Get up and running

Start locally with Docker.

Bring up the UI, API, callback worker, and database with Docker Compose.

Open setup guide →
git clone https://github.com/unnismohan/bss-integration-simulator.git
cd bss-integration-simulator
docker compose up --build -d

# Open the UI at http://localhost:8088

Deployment: This page introduces the project. The interactive simulator requires the API, callback worker, and PostgreSQL, deployed separately using Docker Compose or Kubernetes. See the Kubernetes deployment guide.
