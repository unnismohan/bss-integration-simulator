Open-source integration test tooling

Simulate partner APIs. Test your BSS with confidence.

Configure realistic HTTP partner behavior for development, integration testing, and controlled load tests—without depending on live third-party systems.

Get started Scenario guide

What it supports

Build configurable partner simulations through a guided web interface.

Sync and async flows

Return an immediate response or an acknowledgement followed by a delayed callback with configurable retries.

JSON and XML

Model JSON APIs and XML/SOAP-envelope payloads with request captures and response mappings.

Dynamic response values

Copy values from requests or generate fixed, random, and choice-based response values.

Load and runtime visibility

Use included load generators and monitor simulator throughput, resources, and callback queue health.

How it works

1. Define a scenario

Set the method, endpoint key, request format, and synchronous or callback flow.

2. Map request and reply fields

Paste sample payloads, discover their fields, then map captures and generated values into responses.

3. Point your BSS at it

Call /sim/<scenario-key> and test against the configured partner behavior.

Run locally

Requirements: Docker Engine or Docker Desktop with Docker Compose v2.

git clone https://github.com/unnismohan/bss-integration-simulator.git
cd bss-integration-simulator
docker compose up --build -d

Open the UI at http://localhost:8088. The full setup and deployment details are in the README and Kubernetes deployment guide.

Deployment note: GitHub Pages hosts this project website and documentation links. The interactive simulator requires the API, callback worker, and PostgreSQL; deploy those with Docker Compose or Kubernetes.
